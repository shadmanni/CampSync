# CampusSync — Campus-Verified Single Page Platform

CampusSync is a unified campus platform designed to connect verified college students across 4 core modules:

- **CampusConnect**: Community discussion feed, department updates, and anonymous student confessions.
- **CampusBid**: Student marketplace with real-time auction bidding & verified handoffs.
- **CampusRide & Events**: Carpooling with live seat count tracking and campus gathering RSVPs.
- **CampusNearby**: Local student discounts, partner offers, and community pop-up deals near campus.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shadmanni/CampSync.git
   cd CampSync
   ```

2. **Install dependencies**:
   ```bash
   cd client
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Or from the root directory:
   ```bash
   npm run dev
   ```
